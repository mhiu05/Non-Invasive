# Hướng dẫn chuyển đổi từ SQLite sang PostgreSQL (Supabase)

Chào bạn, việc chuyển đổi toàn bộ cơ sở dữ liệu từ SQLite sang PostgreSQL (Supabase) là **hoàn toàn khả thi** và rất được khuyến khích khi dự án cần mở rộng (scale), vì PostgreSQL mạnh mẽ hơn nhiều trong việc xử lý truy cập đồng thời so với SQLite.

Hiện tại, hệ thống của bạn đang sử dụng 3 file SQLite riêng biệt:
1. `video_jobs.db` (Bảng: `jobs`) - Quản lý trong `app/api/routes/video.py`
2. `history.db` (Bảng: `users`, `history`) - Quản lý trong `app/services/history_store.py`
3. `chatbot_feedback.db` (Bảng: `chatbot_feedback`) - Quản lý trong `app/chatbot/feedback_store.py`

Dưới đây là hướng dẫn chi tiết từng bước để thực hiện việc chuyển đổi này.

---

## Bước 1: Khởi tạo dự án Supabase

1. Truy cập [Supabase](https://supabase.com/) và tạo tài khoản/đăng nhập.
2. Tạo một **Project mới** (New Project).
3. Đợi vài phút để Supabase thiết lập database.
4. Truy cập **Project Settings > Database** để lấy **Connection String** (URI). Nó sẽ có dạng:
   `postgresql://postgres:[YOUR-PASSWORD]@[DB-HOST]:5432/postgres`

## Bước 2: Chuẩn bị bảng (Tables) trên Supabase

SQLite và PostgreSQL có một chút khác biệt về cú pháp. Cụ thể:
- `AUTOINCREMENT` trong SQLite sẽ chuyển thành `SERIAL` hoặc `GENERATED BY DEFAULT AS IDENTITY` trong PostgreSQL.
- Nên chạy các lệnh SQL này trực tiếp trên giao diện **SQL Editor** của Supabase để tạo bảng:

```sql
-- 1. Bảng jobs (từ video_jobs.db)
CREATE TABLE jobs (
    id TEXT PRIMARY KEY,
    status TEXT,
    created_at TIMESTAMP WITH TIME ZONE,
    updated_at TIMESTAMP WITH TIME ZONE,
    result TEXT,
    error TEXT,
    file_path TEXT
);

-- 2. Bảng users (từ history.db)
CREATE TABLE users (
    id TEXT PRIMARY KEY,
    username TEXT,
    email TEXT UNIQUE,
    hashed_password TEXT,
    created_at TIMESTAMP WITH TIME ZONE
);

-- 3. Bảng history (từ history.db)
CREATE TABLE history (
    id TEXT PRIMARY KEY,
    user_id TEXT REFERENCES users(id),
    created_at TIMESTAMP WITH TIME ZONE,
    type TEXT,
    filename TEXT,
    session_id TEXT,
    duration_sec REAL,
    heart_rate REAL,
    blink_rate REAL,
    snr_db REAL,
    age INTEGER,
    age_group TEXT,
    bandpass_low_hz REAL,
    bandpass_high_hz REAL,
    hrv_ms REAL,
    sdnn_ms REAL,
    rmssd_ms REAL,
    pnn50 REAL,
    peak_count INTEGER,
    result TEXT
);

-- 4. Bảng chatbot_feedback (từ chatbot_feedback.db)
CREATE TABLE chatbot_feedback (
    id SERIAL PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL,
    question TEXT NOT NULL,
    answer TEXT NOT NULL,
    sources TEXT,
    rating INTEGER,
    comment TEXT,
    session_id TEXT
);
```

## Bước 3: Thay đổi code Backend Python

Trong Backend, bạn đang sử dụng thư viện `sqlite3` mặc định của Python. Để kết nối với PostgreSQL của Supabase, bạn cần dùng thư viện `psycopg2`.

### 3.1. Cài đặt thư viện

Bạn cần cài đặt thư viện quản lý kết nối PostgreSQL bằng cách thêm vào `requirements.txt` hoặc chạy lệnh sau:
```bash
pip install psycopg2-binary
```

Thêm cấu hình Supabase URL vào file `.env`:
```env
SUPABASE_DB_URL=postgresql://postgres:[YOUR-PASSWORD]@[DB-HOST]:5432/postgres
```

### 3.2. Cập nhật mã nguồn

Trong các file kết nối (vd: `history_store.py`, `video.py`, `feedback_store.py`), thay vì dùng `sqlite3.connect()`, hãy sử dụng `psycopg2`. 

Một số điểm cần **Đặc biệt lưu ý khi chuyển đổi code**:
1. **Placeholder**: SQLite dùng `?` để truyền tham số, còn `psycopg2` dùng `%s`. Bạn phải thay toàn bộ `?` thành `%s` trong các câu query SQL.
2. **INSERT OR REPLACE**: SQLite dùng `INSERT OR REPLACE INTO`. Trong PostgreSQL, bạn sẽ đổi thành `INSERT INTO ... ON CONFLICT (id) DO UPDATE SET ...`.
3. **Dictionary Cursor**: Trong SQLite bạn đang dùng `conn.row_factory = sqlite3.Row`. Với psycopg2, bạn có thể dùng `psycopg2.extras.DictCursor` để có chức năng tương tự.

**Ví dụ chuyển đổi cho `app/services/history_store.py`:**

```python
import psycopg2
import psycopg2.extras
import os

DB_URL = os.getenv("SUPABASE_DB_URL")

def _get_conn():
    # Sử dụng DictCursor để trả về kết quả giống dạng dictionary như sqlite3.Row
    conn = psycopg2.connect(DB_URL, cursor_factory=psycopg2.extras.DictCursor)
    return conn

def save_history_record(record: dict) -> str:
    # ... logic tạo id ...
    conn = _get_conn()
    with conn.cursor() as cur:
        cur.execute(
            """
            INSERT INTO history (
                id, user_id, created_at, type, filename, session_id, duration_sec,
                heart_rate, snr_db, age, age_group, bandpass_low_hz,
                bandpass_high_hz, hrv_ms, sdnn_ms, rmssd_ms, pnn50, peak_count, result
            ) VALUES (
                %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s
            ) ON CONFLICT (id) DO UPDATE SET
                user_id = EXCLUDED.user_id,
                result = EXCLUDED.result,
                duration_sec = EXCLUDED.duration_sec;
            """,
            (
                history_id, user_id, created_at, record.get("type"), record.get("filename"),
                record.get("session_id"), record.get("duration_sec"), record.get("heart_rate"),
                record.get("snr_db"), record.get("age"), record.get("age_group"), 
                record.get("bandpass_low_hz"), record.get("bandpass_high_hz"), 
                record.get("hrv_ms"), record.get("sdnn_ms"), record.get("rmssd_ms"), 
                record.get("pnn50"), record.get("peak_count"),

            )
        )
    conn.commit()
    conn.close()
    return history_id
```

## Bước 4: Chuyển dữ liệu cũ từ SQLite sang Supabase

Nếu bạn muốn giữ lại dữ liệu hiện có trong các file `.db`, bạn có thể dùng một công cụ chuyển đổi hoặc viết một script nhỏ bằng Python:

```python
import sqlite3
import psycopg2

sqlite_conn = sqlite3.connect("backend/history.db")
sqlite_conn.row_factory = sqlite3.Row

# Kết nối Postgres
pg_conn = psycopg2.connect("postgresql://postgres:[PASSWORD]@[HOST]:5432/postgres")

cur_lite = sqlite_conn.cursor()
cur_pg = pg_conn.cursor()

# Migrate bảng users
cur_lite.execute("SELECT * FROM users")
users = cur_lite.fetchall()
for u in users:
    cur_pg.execute(
        "INSERT INTO users (id, username, email, hashed_password, created_at) VALUES (%s, %s, %s, %s, %s) ON CONFLICT DO NOTHING",
        (u["id"], u["username"], u["email"], u["hashed_password"], u["created_at"])
    )

pg_conn.commit()
print("Migration completed!")
```

## Tổng kết

Việc chuyển qua PostgreSQL (Supabase) sẽ giúp hệ thống đồng bộ hơn, bảo mật tốt hơn và xử lý đa luồng an toàn hơn khi server chạy ở môi trường thực tế (production).
Nếu bạn muốn dùng một cách chuyên nghiệp hơn trong Python thay vì dùng `psycopg2` viết SQL thuần (raw SQL), bạn có thể cân nhắc dùng ORM như **SQLAlchemy**, nó sẽ giúp tương thích cả SQLite lẫn PostgreSQL chỉ bằng cách đổi URL cấu hình mà không cần sửa câu truy vấn.
